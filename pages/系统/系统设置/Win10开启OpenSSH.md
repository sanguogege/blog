# Win10 开启 OpenSSH

## 图片较多，请移步 [win10 开启 OpenSSH 服务](https://blog.csdn.net/qq_21874123/article/details/105428708)

1. 打开设置 ------ 应用 ------ 可选功能 ------ 添加功能 ------ 找到 OpenSSH、OpenSSH 选择安装就可以了。
   ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/a2bc1594a12dfc3236c7b0af460bacfc.png)
   ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/47f3507134fdc98353d3256d772453a9.png)
   这样就算是安装成功了
   ![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/20bf0059145634ceb651ef0e4daf37d8.png)
2. 安装完成后验证以下就可以了。cmd 或者 powershell 输入 ssh，出现以下就是客户端安装成功了。
