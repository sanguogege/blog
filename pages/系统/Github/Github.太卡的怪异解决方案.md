# Github.com 太卡或者连不上怎么办

# 图片较多，请移步 [ Github.com 太卡或者连不上怎么办](https://blog.csdn.net/qq_21874123/article/details/120422737)

看了很多网上的教程，无非就是改 host，然而不知道是家里联通太坑还是咋滴。改了最多顶一会。。

这困扰了我很久，知道今天突然看待一个新的方法，一试果然 ok 了。虽然时快时慢，但这比之前改 host 快了不知道多少，由于和我的 win10 操作差不少，特地记录下。。

1、打开设置，然后打开网络。
![嘿嘿](https://i-blog.csdnimg.cn/blog_migrate/694a5251d0126a59a4099d75bcc75321.png#pic_center)

2、找到网络和共享中心！![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/9bf0ffdb072730ee1ffb2e778d2bf37d.png#pic_center)

3、然后点击左下角的 internet 选项！
![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/0d2923d90036537295468553aaf77f33.png#pic_center)

4、点击链接，然后找到局域网设置。![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/d1979da6c1bb598701eff0ee282ef9e1.png#pic_center)

5、把自动检测设置勾选上。。![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/64dff532211975613d132de56407852b.png#pic_center)

然后完成。。。。。

就可以愉快的交友啦！！
