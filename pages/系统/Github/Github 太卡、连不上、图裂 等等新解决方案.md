# 图片较多，请移步 [ Github 太卡、连不上、图裂 等等新解决方案](https://blog.csdn.net/qq_21874123/article/details/121273369)

之前分享过关于 Github 浏览太卡、连不上的问题的解决方案，当时确实感觉良好。但后来一看，还是一个坑爹方案，不过由于我常用的是 gitee（也就是码云），所以有段时间没注意到。

现在我又发现一个十分好的解决方案，但是需要安装一个自动更新 host 的软件，解决方案来源于 github 上。

首先，推荐插件 [faster-hosts](https://github.com/gauseen/faster-hosts),效果类似于**GitHub 加速**这个工具，但 GitHub 加速经常不稳定（而且这个和下面那个文章来源是一个作者的东西），所以推荐这个，但这个只是一个开胃菜，后面的才是重点。

我也懒得多打字了，抄录一点上来，使用方法就是修改 host。

下载**SwitchHosts **这个软件，这是下载地址[SwitchHosts 下载地址 1](https://www.electronjs.org/apps/switchhosts)、[SwitchHosts 下载地址 2](https://oldj.net/article/2011/10/20/switchhosts/)、[SwitchHosts 下载地址 3](https://github.com/oldj/SwitchHosts)，3 是 github 的地址。

长这个样子，我的版本是 4.03！！！![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/b7f2c18bea63e354bdeb321475877406.png#pic_center)
使用方法。

1、**注意一定要使用“以管理员的方式打开”**，然后如图。

![在这里插入图片描述](https://i-blog.csdnimg.cn/blog_migrate/d3011e4f58dfb760e34dc2ae0377125f.png#pic_center)
然后就点击那个绿色的小开关（管理员的方式才有权限读写）就可以了。然后若是没有效果，推出软件重新登陆即可。

这次我使用了好久都没有问题。。
